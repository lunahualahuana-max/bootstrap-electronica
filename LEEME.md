# Tarea 05 — TecnoBox

Tienda demostrativa de tecnología hecha con Bootstrap 5. Incluye carrusel, menú adaptable, catálogo, secciones de celulares, laptops y tablets, y contador de bolsa.

## Abrir en Visual Studio Code

1. Abre `index.html`.
2. Haz clic derecho y elige **Open with Live Server** (o pulsa **Go Live**).
3. Necesitas conexión a internet para cargar Bootstrap desde su CDN. Las imágenes están en `img/`.

Los precios y textos son ejemplos para la práctica; el botón Agregar solo actualiza el contador, no procesa compras.
